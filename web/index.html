SKILL.md — Automated Pre-PR Organizational Context Gate

          
# ShipGate Context — Open-Source Agent Skill (SKILL.md)
1. Extract Jira issue key from Git branch (e.g. feat/PAY-482 -> PAY-482).
2. Call `fetch-context-graph` (depth=2) via Atlassian MCP to load governed
   Confluence ADRs, Compass service owners, and 2-hop JSM postmortems.
3. Pass modified config keys or SQL DDL to `verify-adr-compliance`:
   - If status == "BLOCKED" or CRITICAL adrViolations > 0, apply the ADR
     remediationHint locally before opening a Pull Request.
4. Call `create-mitigation-subtasks` for mandatory load-test / SRE checks.
5. Once confidenceScore >= 85 (SHIP_READY), call `log-release-attestation`.
